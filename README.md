## 💡 解決する課題

### ターゲットユーザー
- 🎓 **教育関係者**: 水族館、海洋教育施設のスタッフ
- 🎣 **釣り愛好家**: 魚の知識を深めたい人
- 🤿 **レジャーダイバー**: ダイビングをもっと楽しみたい人
- 📚 **生物学学習者**: 魚類の分類を学習したい学生

### 課題と解決策

| 課題 | 解決策 |
|------|--------|
| 魚の名前を覚えるのが難しい | 画像と名前を結びつけるクイズ形式 |
| 学習の継続が困難 | スコア履歴とグラフによる進捗可視化 |
| 一度覚えてもすぐに忘れる | 間違えた問題だけを復習できる機能 |
| 幅広い種類をカバーできない | 905種類の魚データを収録 (今後拡大予定) |

### 1. 学習効果の最大化
- **即時フィードバック**: 回答後すぐに正解・不正解を表示
- **間違い復習機能**: 苦手な魚だけを集中的に学習
- **進捗の可視化**: グラフで学習の成果を実感

### 2. 使いやすさの追求
- **3ステップで開始**: カテゴリー選択 → 絞り込み → クイズ開始
- **リアルタイム件数表示**: 絞り込み結果が即座に分かる
- **デバイス対応**: スマホでも快適に利用可能

### 3. モチベーション維持
- **達成感の演出**: 正解率に応じたメッセージ
- **記録の蓄積**: 最高正解率、平均正解率の表示
- **成長の実感**: 折れ線グラフで上達を可視化

## 🎮 使い方（学習の流れ）

### STEP 1: 学習範囲を選ぶ（設定画面）

まずは、学びたい魚のカテゴリーを選びます。

- **カテゴリー選択**: 27種類から選択（例: サメ・エイの仲間、ウツボ・アナゴの仲間）
- **分類選択**: さらに詳細な分類で絞り込み（例: カスザメ科、ウツボ科）
- **対象の魚**: リアルタイムで件数が表示され、学習範囲が一目で分かる
- **クイズを始める**: 絞り込んだ魚から最大10問をランダム出題

💡 **ポイント**: 初めての方は1つのカテゴリーから始めるのがおすすめです。

### STEP 2: クイズに挑戦する（クイズ画面）

魚の画像を見て、名前を当てます。

- **魚の画像**: 問題の魚の画像が表示
- **名前を入力**: 思いついた名前を入力（分からない場合は空欄でもOK）
- **即時判定**: 回答すると、すぐに正解・不正解が表示
  - ✓ 正解なら緑色で「正解！」
  - ✗ 不正解なら赤色で正しい名前を表示
- **次の問題へ**: 全10問を順番に解いていく

💡 **ポイント**: 不正解でも正解名が表示されるので、その場で覚えられます。

### STEP 3: 結果を確認する（スコア画面）

クイズ終了後、成績が表示されます。

- **間違えた問題だけやり直す**: 苦手な魚を集中的に復習
- **もう一度挑戦する**: 設定画面に戻って新しいクイズに挑戦

💡 **ポイント**: 間違えた問題を復習することで、効率的に知識を定着できます。

---

### STEP 4: 成長を確認する（スコア履歴画面）

学習の進捗を可視化して、モチベーションを維持。

- **折れ線グラフ**: 過去の正解率の推移を一目で確認
- **統計情報**:
  - 挑戦回数
  - 平均正解率
  - 最高正解率
- **履歴の削除**: 新しくスタートしたい時は履歴をリセット可能

💡 **ポイント**: グラフが右肩上がりになると、成長を実感できます！

## 💾 データ管理とプライバシー

このアプリケーションは、**すべてのデータをブラウザ内に保存**します。サーバーへのデータ送信は一切ありません。

### 保存されるデータ

| データ | 保存場所 | 保持期間 | 用途 |
|--------|---------|---------|------|
| **スコア履歴** | localStorage | 手動削除まで | 学習の進捗を記録（最大50件） |
| **復習データ** | sessionStorage | タブを閉じるまで | 間違えた問題を一時保存 |

### プライバシー保護

- ✅ **サーバー送信なし**: すべてのデータはブラウザ内のみで完結
- ✅ **個人情報不要**: 名前やメールアドレスの登録は不要
- ✅ **完全削除可能**: 履歴はいつでも削除できます
- ✅ **オフライン対応**: インターネット接続なしでも動作（初回読み込み後）

## 🔧 トラブルシューティング

### よくある質問

<details>
<summary><strong>開発サーバーが起動しない場合</strong></summary>

ポート3000が既に使用されている可能性があります。

```bash
# 別のポートで起動
pnpm dev -- -p 3001
```

</details>

<details>
<summary><strong>画像が表示されない場合</strong></summary>

以下を確認してください：

1. `public/images/` ディレクトリに画像ファイルが存在するか
2. `public/fish_images.jsonl` の `filename` フィールドが正しいか
3. ブラウザのキャッシュをクリアしてリロード

</details>

<details>
<summary><strong>スコアが重複して記録される場合</strong></summary>

**原因**: React 18のStrictModeは開発モードで`useEffect`を2回実行します。

**対策**: `useRef`を使用した重複防止機能を実装済みです。本番環境では発生しません。

</details>
